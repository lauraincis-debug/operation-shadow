# 🚀 Déployer Football AI Ultra sur Firebase Hosting

Bienvenue dans l'assistant de déploiement **Google Cloud Shell** pour **⚡ Football AI Ultra v2** !

---

## Étape 1 — Créer ou récupérer votre ID Projet Firebase

1. Dans un autre onglet, ouvrez **[console.firebase.google.com](https://console.firebase.google.com/)**.
2. Créez un projet (plan gratuit **Spark**) ou cliquez sur votre projet existant.
3. Relevez l'**ID du projet** (exemple : `football-ai-ultra-2026`).

---

## Étape 2 — Lancer le déploiement en 1 commande

Cliquez sur le bouton copier de la commande ci-dessous et validez dans le terminal en bas :

```bash
chmod +x deploy-firebase.sh && ./deploy-firebase.sh
```

1. Autorisez la connexion Firebase si un lien s'affiche, puis collez le code d'autorisation.
2. Entrez l'**ID de votre projet Firebase**.
3. Patientez quelques secondes : le dossier de production `www/` est envoyé en ligne !

---

## Étape 3 — Ouvrir votre application en ligne 🎉

Votre application **PWA installable** est maintenant en ligne à l'adresse :
`https://VOTRE-ID-PROJET.web.app`
